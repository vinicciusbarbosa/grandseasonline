# Boneco base para o DragonBones

- `base_ske.json` + `base_tex.json` + `base_tex.png`: projeto pronto (formato
  DragonBones 5.5) com dois esqueletos: `base_frente` (3/4 de frente) e
  `base_costas` (3/4 de costas). Ossos já nas juntas, peças já encaixadas.
  No DragonBones Pro: **File → Import** e escolha `base_ske.json`.
- `pecas/`: as mesmas peças soltas (PNG transparente), caso queira montar do zero.

Ao terminar, exporte em **File → Export → Data Version 5.5, JSON + Texture
Atlas** e coloque os 3 arquivos de volta nesta pasta.
